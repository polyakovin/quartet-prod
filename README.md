# Qwertophone

[Open the production app](https://polyakovin.github.io/quartet-prod/)

Production builds of the Qwertophone browser music app.
[Source repository](https://github.com/polyakovin/quartet).

Current release: **v0.1.0**.

The shared library contains six public-domain or CC BY themes. The private
local repertoire is excluded from this deployment.

Build provenance and validation results are recorded in `release.json`.
This release was built from the verified source working tree; its baseline
Git revision is recorded separately from the build-input fingerprint.

To host the downloaded web archive, serve its files below `/quartet-prod/`.
